# Authentication System

Console-based Authentication System built with Core Java.
Features register, login, SHA-256 password hashing, session management, and role-based access.

## Features

- User Registration
- Secure Login (SHA-256)
- Session Management with Tokens
- View All Users (sorted)
- Logout
- Password Validation
- Custom Exceptions

## Topics Covered

- Abstract Class
- Enum
- Immutable Class
- Static Nested Class
- Inner Class
- Local Class
- Anonymous Class
- Object Class (equals, hashCode, toString)
- AutoBoxing
- Scanner
- BufferedReader
- InputStreamReader
- InputStream
- Custom Exception
- SHA-256 Hashing
- HashMap
- try-catch
- Session Management

##Tech Stack

- Language: Java
- Type: Console Application
- Storage: In-Memory (HashMap)
- Hashing: SHA-256
- JDK: 8+

## How to Run
1. Compile all files
2. Run Main.java
